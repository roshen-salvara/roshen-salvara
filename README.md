# Roshen Warrier

Founder and Product/Solutions Lead at [Salvara](https://salvara.ai), building AI agents, source-traceable data platforms, procurement workflows, and enterprise integrations.

## What I’m building

- **Salvara:** A machine-readable, verifiable data layer designed for agentic commerce—where software agents need evidence they can inspect before acting.
- **Muster:** An AI-enabled procurement engine in pilot and beta testing with multiple property-management teams.
- **Public-record intelligence:** A national data platform covering nearly 14 million U.S. businesses across 44 states, with dated observations, source capture, validation, geospatial search, and API-ready data.
